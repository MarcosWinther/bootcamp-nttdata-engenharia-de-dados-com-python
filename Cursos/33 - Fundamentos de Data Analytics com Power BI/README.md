# 📖 Fundamentos de Data Analytics com Power BI

## 📝 Análise de Dados

- Segundo a Microsoft:
	- "Ao reduzir o trabalho manual, a análise avançada pode, em última análise, ajudar as organizações a tomar melhores decisões empresariais e criar resultados acionáveis e significativos".

- Tradicionamente, a análise de dados era uma tarefa complexa que era realizada por engenehiros.


### Simplificação - Power BI:
	- Recursos visuais;
	- Estásticas;
	- Recursos de IA.
	

### Aplicando Análise de Dados com Power BI:

- Explorar o resumo estatístico;
- Identificar exceções com visuais do Power BI;
- Agrupar e compartimentalizar dados para análise;
- Aplicar técnicas de clustering;
- Conduzir análise de série temporal;
- Usar o recurso ***Analisar***;
- Usar visuais personalizados de análise avançada;
- Examinar insights rápidos;
- Aplicar Insights da IA.

## 📝 Resumo Estatístico

- O resumo estatístico é a informação que fornece uma descrição rápida e simples de seus dados.
- Como?
